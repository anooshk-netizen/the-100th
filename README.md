# The 100th

One sheep is lost. The 99 are safe. Help the Shepherd find the one.

A rare-answer Bible trivia game based on the Parable of the Lost Sheep (Luke 15:3–7). Give the answer you think few others will, but it has to be right. The rarer your answer, the further the Shepherd searches.

Play it: open `index.html` in a browser. No build step.

Rarity percentages are placeholder estimates until the seed survey runs.
